# 路线图

更新日期：2026-11-10

## 当前优先级

### P0：补全微博内容

- 每日继续执行 `wbq.py fetch --mode snapshot --resume`，遵守 4–8 秒间隔、每 30 页休眠和单次 500 请求上限。
- 目标覆盖截至 2026-11-09 的存量微博（含更早历史）。
- 抓取结束后先同步 N宗罪条目关联，再运行分类整理。

### P0：热门

- 保持全量微博按互动热度排序，使用稳定分页。
- 不把“热门”限制为高转评微博，避免新内容和长尾内容无法进入。

### P0：N宗罪

- 以人工维护的罪名/行为条目为核心，而不是只做关键词全文搜索。
- 每个条目支持别名、排除词、行为标签和站内搜索词。
- 一条微博可以关联多个罪名，保留多对多关系。
- 当前条目：吃屎、偷吃、收礼、胖瘦二象性。胖瘦二象性使用 22 条人工审定微博。
- N宗罪 query pack 区分高精度自动公开词和宽泛候选词；baseline 按版本冻结并保存检索来源。
- 新增条目和宽词规则后，复查误收和漏收，再更新阈值。

### P0：互动

- 保留与 `@比格犬受害者联盟` 的正文提及和转发源匹配。
- 继续展示源微博正文、全部图片和可播放视频。
- 后续补充互动微博的评论图片，但先保证微博本体完整。

### 分类方向

1. **来源特征**：原创、转发、评论区、超话；评论点赞数；博主是否点赞；超话热度。
2. **技术特征**：分辨率、宽高比、清晰度、噪点、压缩痕迹、文字/水印占比、截图/表情包/拼图识别。
3. **视觉与审美**：主体是否清晰、狗狗占比、构图、色彩、可爱度、自然风景感、壁纸适配度、明信片适配度。
4. **负向特征**：截图、文字过重、广告、商品、低清、模糊、拼图、视频/live 帧。

### 评分管线

- 先用尺寸、宽高比、来源和转评做预筛。
- 再用 `deepseek-flash` 对预筛候选输出结构化 JSON 分数和标签。
- 分别生成“手机壁纸”和“明信片”两个排序，避免一套排序兼顾两种用途。
- 每条图片保留来源、作者、原微博/评论链接；饭制图只做预览和外链。

### 数据模型

新增逐图记录，而不是只在 `posts.pics_json` 上打分：

- `image_id`、`post_id`、`comment_id`
- `source_type`：post / comment / supertopic
- 作者、宽高、原图/缩略图 URL
- 来源热度：评论赞、超话排名、微博转评赞
- 模型分数：清晰度、构图、可爱度、美感、壁纸、明信片、文字干扰
- 人工状态：待审、精选、排除

### 校准与验收

- 需要用户提供 10–20 张壁纸正样本、10–20 张明信片正样本和 5–10 张负样本。
- 先人工验收前 30 张，再决定是否拆成两个高清图子 tab。
- 验收标准是“用户愿意设为封面或做成明信片”，不是单纯的转评数。
