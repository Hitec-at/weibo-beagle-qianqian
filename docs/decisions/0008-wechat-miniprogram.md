# 微信原生小程序与云托管只读后端

日期：2026-11-19

## 决定

正式入口迁移为微信原生小程序。小程序通过 `wx.cloud.callContainer` 调用微信云托管中的 FastAPI，生产数据由云托管 Serverless MySQL 提供。抓取、审核和运营继续在本地执行。

## 理由

- 原生 WXML、WXSS 和 JavaScript 减少跨端适配。
- `callContainer` 使用微信私有协议，不依赖业务域名。
- 主链路不需要 ICP 备案、域名申请或自有 HTTPS 证书。
- 关闭云托管公网访问后，服务只允许授权小程序调用。
- 本地 SQLite 继续承担抓取和审核，线上数据库只保存发布镜像。
- 现有网站和 Fly.io 部署保留为付费备用路径。

## 边界

- 云托管容器不保存业务数据；生产读取 MySQL。
- 小程序不提供抓取、审核、登录、投稿或运营后台。
- 图片来源优先使用微博图床直链；必要时通过 `callContainer` 返回小体积图片。
- 视频优先使用游客直链或短期缓存，不承诺依赖长期 Cookie 播放。
- `callContainer` 单次最多 15 秒，返回包最多 1000 KiB。

## 备用

已有 Fly.io + SQLite 继续作为 Web 备用部署。备用路径不会被小程序 `callContainer` 直接调用。
