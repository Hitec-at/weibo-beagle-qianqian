# 规则变更审计采用轻量只读方案

- 状态：采用
- 日期：2026-11-16
- 关联：Issue #84、`docs/review/rule-change-audit-v1.md`、`rule_audit.py`

## 背景

微博存量尚未完整，规则样本会持续增加。此时使用覆盖率、召回率或小样本精确率
调阈值，容易把阶段性数据特征误当成长期规律。

## 决定

规则变更先做确定性只读检查，再由独立子智能体做语义盲审。检查只覆盖定义完整性、
证据与反例、可能历史回归、删除残留四项。

审计结论只有 approve、warn、block。样本不足必须标为 warn，不得仅因样本少而
block，也不得自动补样、调阈值或修改规则。删除后仍有公开关联时默认 block，要求
先完成暂停或废弃生命周期。

## 备选方案

- 全量覆盖率评估：会受未完整语料影响，暂不采用。
- 每年规则都要求三名模型投票：成本高，而且同模型投票仍可能共享盲区，暂不采用。
- 只记录 warning、不阻断删除残留：会让废弃规则继续公开，风险不可接受。

## 取舍

这套方案不能准确估计召回率，也不能保证不同模型判断完全一致。它优先保证可解释、
低成本和不污染现有数据，等存量完整后再评估更重的统计评估。
