# 粉丝二创分类与 N宗罪分离

- 状态：采用
- 日期：2026-11-16
- 关联：Issue #71、`memes.seed.toml`、`docs/glossary.md`、`app/main.py`

## 背景

“胖爪爪”和“村长”来自粉丝对钱钱形象的虚构编排，并非钱钱真实发生的行为。如果直接放进 N宗罪，会让页面把观众创作误读为现实事实；如果只作为普通别名，又会丢失稳定的故事线和页面入口。

## 决策

1. 新增用户可见的“粉丝二创”分类入口，代码分类为 `fan_memes`。
2. `胖爪爪`（`pangzhuazhua`）和`村长`（`cunzhang`）是两个独立的二创分类，仍共用现有 `post_memes` 关联和详情页。
3. 分类条目增加 `kind` 字段：`behavior` 表示行为或现实主题，`fan_fiction` 表示粉丝虚构叙事。
4. 分类整理根据关联条目类型分别写入 `memes` 和 `fan_memes` 总分类，禁止把二创条目计入 N宗罪总关联。
5. “村长”继续作为钱钱实体别名用于正文索引，同时作为二创分类名称使用，两者用途分开记录。

## 备选方案

- 直接放入 N宗罪：实现简单，但会把虚构叙事包装成现实行为，不采用。
- 只保留为实体别名：不会显示独立分类页，也会丢失跨帖故事线，不采用。
- 新建完全独立的数据表：隔离最强，但当前体量和查询方式不需要复制整套关联逻辑，暂不采用。

## 后果

二创内容会有独立入口，并且仍可进入详情页和每日分类统计。后续新增二创梗时必须标记 `kind = "fan_fiction"`；不能仅因评论中提到人物或行为就自动升级为现实事实。
