# 候选分类边界调整

- 状态：采用
- 日期：2026-11-14
- 关联：Issue #65、`memes.seed.toml`、`docs/glossary.md`、候选审核 few-shot

## 背景

2026-11-13 的人工审核发现，旧规则把部分项目语境理解得过窄，导致已经能够说明问题的微博仍被送进“不确定”队列。审核结果同时确认了“吃屎”和“翻垃圾”的边界，以及“胖瘦二象性”和“收礼”在账号语境中的稳定用法。

## 决策

1. 偷有屎的纸尿裤视为吃小孩屎。只翻找或食用垃圾桶内容仍归翻垃圾，不归吃屎。
2. 主人或其他人口中称呼钱钱胖、瘦，并引发或通常引来评论区身材体重讨论的微博，可以归入胖瘦二象性。该条目不再要求正文同时出现体重变化和饮食控制两个环节。
3. 晒钱钱的快递可以归入收礼。项目语境中钱钱快递约 99% 由网友寄送，主人自购物品通常不会特意晒出。
4. 同时命中偷吃的微博不因该关联自动新增胖瘦二象性。
5. 人工最终关联继续使用 `matched_by = "human"`，规则同步不得删除或覆盖。

## 备选方案

继续只靠通用关键词把所有“纸尿裤”“垃圾桶”“胖”“瘦”“快递”直接归入对应条目。该方案误收范围过大，也会继续把只翻垃圾桶和只偷吃后节食的微博错误归类，因此不采用。

## 后果

高精度短语可以直接进入公开关联，泛词继续停留在候选池。规则回放必须符合 2026-11-13 的人工决定，且 `memes-import` 重建生成关联时保留人工关联。后续扩展称呼或快递规则时，仍需补充正反例后再加入高精度词。
