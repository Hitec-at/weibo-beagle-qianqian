# 公开代码仓库并公开数据 Release

- 状态：采用
- 日期：2026-11-12
- 关联：Issue #9

## 背景

项目希望公开代码，方便复用、审查和贡献。微博正文和被采集到的评论本身来自公开
页面，用户确认这些公开数据可以随代码仓库一起发布。

## 决策

- 直接把现有私有仓库转为公开，不另建无历史的新仓库。
- 历史提交、标签、分支、Actions 记录和 `data-*` Release 资产一并公开。
- 代码使用 MIT License；该许可只覆盖软件代码，不改变第三方微博、评论、图片或
  其他内容的权利归属。
- 抓取 Cookie、生产 Token、本地 `.env`、SQLite 工作库和 `*.private` 配置继续
  保持不公开。

## 备选方案

- 新建无历史的干净公开仓库：能隐藏历史，但维护两个仓库和数据迁移成本更高。
- 公开代码、数据 Release 继续私有：需要引入额外私有对象存储和部署鉴权，当前
  没有必要。

## 后果

仓库公开后，历史内容和 Release 资产可能被下载、缓存或 fork，之后即使改回私有
也不能撤回已公开内容。提交前必须持续执行凭据扫描；出现误提交时应立即轮换凭据、
清理资产并记录影响范围。
