# 项目统一语言表

更新日期：2026-11-14

本表定义项目中强上下文、容易跨会话漂移的术语。外部标准词保留原义并注明来源；项目自建词只在本项目范围内成立。

## 使用规则

- 状态：`提议` 表示尚待确认，`采用` 表示已成为项目正式用语，`废弃` 表示不再使用但保留迁移映射。
- 用户可见名称、代码标识和历史别名必须分开记录。
- 定义只说明“是什么”；重大取舍记录在 [`docs/decisions/`](decisions/README.md)，优先级记录在 [`docs/roadmap.md`](roadmap.md)。
- 新增术语前，先在对话中给出候选定义、正例、反例和改名影响；用户确认后再写入本表。
- 外部理论词引用规范来源，不把工程封装包装成学术标准。

## 核心术语

| 术语 | 状态 | 定义 | 边界与映射 |
|---|---|---|---|
| 项目统一语言 | 采用 | 项目成员、文档、代码和会话共同使用的术语及定义集合。 | 对应领域驱动设计中的 Ubiquitous Language；本表是项目内的单一入口。 |
| N宗罪 | 采用 | 用户可见的专题体系，汇总比格钱钱反复出现的热梗、行为和故事线。 | 不表示真实法律评价；可包含“吃屎”“偷吃”“收礼”“胖瘦二象性”“翻垃圾”等条目。代码标识为 `memes`；旧称“热梗”不再作为正式名称。 |
| 吃屎 | 采用 | 钱钱食用粪便的行为条目。 | 正文或媒体直接证明食用粪便，或偷“有屎的纸尿裤”，均属于吃屎；只翻找或食用垃圾桶内容属于翻垃圾，不属于吃屎。代码标识为 `chishi`。 |
| 胖瘦二象性 | 采用 | 围绕钱钱胖瘦变化及外界评价形成的体重讨论条目。 | 主人或其他人口中称呼钱钱胖、瘦，并引发或通常引来评论区身材体重讨论的微博可以归入；不再要求正文同时出现体重变化和饮食控制两个环节。其他狗、商品重量及只围绕偷吃后节食的微博不算。代码标识为 `pangshou-erxiangxing`。 |
| 收礼 | 采用 | 网友寄给钱钱家的礼物和快递条目。 | 钱钱的快递晒图可归入；项目语境中钱钱快递通常由网友寄送，主人自购物品通常不会特意晒出。商品售卖和广告不算。代码标识为 `shouli`。 |
| 翻垃圾 | 采用 | 钱钱翻找、掏取垃圾桶或捡食地面食物的行为条目。 | 必须体现翻找、掏取垃圾桶，或吃垃圾桶及地面上的食物；垃圾桶入镜和售卖纸箱不算。代码标识为 `fanlaji`，历史别名 `fanguoji` 保留映射。 |
| 罪证 | 采用 | 被关联到某个 N宗罪条目的微博证据。 | 一条微博可以是多个罪名的罪证；关联表为 `post_memes`。 |
| 代表微博 | 采用 | 人工指定的、用于说明某个 N宗罪条目的典型微博。 | 对应种子字段 `representative_url`；只用于展示和校验，不等于该罪名的全集。 |
| query pack | 采用（规划中） | 每个 N宗罪条目的结构化检索与判定规则包。 | 项目自建工程术语，不是学术标准；包含检索词、别名、排除词、行为标签、判断边界和人工样本。规划见 Issue #18。 |
| 检索规则包 | 提议 | `query pack` 面向非技术用户时的解释性称呼。 | 当前不是页面控件名称；若成为 UI 文案，需单独确认。 |
| 候选池 | 提议 | 由微博搜索、宽泛关键词或模型发现，但尚未达到公开展示标准的一组微博。 | 候选不等于罪证，默认不进入 N宗罪页面。 |
| 人工审定 | 采用 | 由运营者明确确认后建立的内容关联。 | 对应 `match_mode = "curated"` 和 `matched_by = "curated"`；实现位于 `memes.seed.toml` 与 `memes.py`。 |
| 规则关联 | 采用 | 由正文、别名和排除词等确定性规则建立的内容关联。 | 对应 `match_mode = "rule"` 和 `matched_by = "rule"`；规则命中不自动等于高置信。 |
| 高精度规则 | 提议 | 经过样本评估、误收率可接受，可直接进入公开展示层的规则。 | 仍需版本和来源记录；当前尚未形成独立发布层。 |
| 三层来源 | 提议 | 目标数据模型：人工审定、高精度规则、待审核候选。 | 当前已实现人工审定与规则关联；“待审核候选”和独立的高精度发布层仍在规划中。 |
| 互动 | 采用 | 正文或转发源提及 `@比格犬受害者联盟` 的微博集合。 | 页面路径为 `/interactions`；匹配口径以 `config.py` 中的互动账号配置为准。 |
| 萌钱CP | 采用 | 比格犬受害者联盟（比害盟，谐音“萌”）与钱钱的虚拟关系线。 | 互动子分类；包含官方互cue、单方面示爱、网友官宣和 CP 催更。代码标识为 `interaction_mengqian_cp`，页面路径为 `/interactions/mengqian-cp`。 |
| 钱钱实体别名 | 采用 | 粉丝二创中稳定指代钱钱的不同身份称呼。 | 当前高置信词为“村长”“胖媳妇”“老猪”“公公”；用于正文索引，不单独触发任一 N宗罪。 |
| 高清图 | 采用 | 含图、非视频、非 live，并达到转评热度阈值的图片微博集合。 | 页面路径为 `/photos`；当前阈值由 `PHOTO_MIN_ENGAGEMENT` 控制，不代表已完成审美或版权审核。 |
| 引用边界 | 采用 | 公开站只展示短引文、缩略预览和原微博入口，不保存原图。 | 图片通过白名单 `/img` 代理预览；下载和原图查看跳转微博。 |
| 数据快照 | 采用 | 从本地 SQLite 导出的、用于复现和部署的不可变微博数据资产。 | 生产审计使用不可变的 `data-*` Release；`data-latest` 只是便利别名。 |
