# 钱田村治理与上贡

- 状态：采用
- 日期：2026-11-16
- 关联：Issue #71、Issue #76、二创分类 `cunzhang`

## 定义

“钱田村治理与上贡”是粉丝围绕比格钱钱形成的连续性拟人化叙事。粉丝把钱钱和主人的生活空间称为“钱田村”，把钱钱想象成村长，再把它翻垃圾桶、收快递和与网友互动等公开内容编排成村庄治理、垃圾分类、上贡和受贿的滑稽故事。该叙事属于观众二创，不表示钱钱真实担任村长或真实受贿。

## 身份设定

- 钱钱被塑造成“钱田村村长”或“村干部”。
- 主人、弟弟和妹妹等现实角色可以出现在村庄故事中，但角色关系以粉丝评论中的解释为准。

## 垃圾分类与治理梗

- 翻垃圾桶、检查垃圾和巡视村庄被解释成村长处理村务。
- 该故事线关联真实内容中的翻垃圾行为，但“治理”和“村干部”是观众赋予的虚构身份。

## 上贡、收礼与贿赂叙事

- 网友寄送快递被评论描述为“上贡”或“贿赂”。
- 品牌送礼会被进一步包装成品牌公关、代言或村庄经济叙事。
- 这类评论属于观众解释层，不能把“受贿”写成钱钱现实中的行为事实。

## 与真实行为的边界

- 微博正文、图片和视频仍是现实行为的首要证据。
- 评论和语义文档可以说明观众如何命名、解释和关联内容。
- “村长”“钱田村”“上贡”“受贿”是二创语境中的角色和叙事词，不等于行政身份或法律评价。
