# 称重、胖瘦与庆祝性进食

- 状态：采用
- 日期：2026-11-19
- 关联：Issue #105、N宗罪分类 `pangshou-erxiangxing`、语义文档“钱田村治理与上贡”

## 定义

“称重、胖瘦与庆祝性进食”是粉丝围绕钱钱上秤、体重数字、照片显瘦和胖瘦矛盾评价形成的连续玩笑。粉丝常把体重波动解释成减肥成果，再安排一顿庆祝性进食，使“减肥”和“加餐”互相抵消。

这些内容属于观众对公开画面的解释和二次叙事。称重数字、体型评价和庆祝理由不能脱离原微博语境，直接套到其他狗、商品重量或未明确主体的内容上。

## 常见叙事

- 上秤读数、数字纠正和“波动”被当成正在进行中的体重管理记录。
- 同一组照片会被同时评价为“很瘦”和“很胖”，形成胖瘦二象性的笑点。
- 粉丝会把“减肥成功”与“吃一顿庆祝”接在一起，用庆祝性进食重新制造体重矛盾。
- “村长”等身份别名可以和体重叙事叠加，但不因此证明钱钱真的担任公共职位。

## 与分类规则的边界

- 主人或其他人的明确胖瘦评价，可以支持“胖瘦二象性”分类，但仍以原微博正文、图片和视频为首要证据。
- 单纯加餐、没吃饱、商品重量、其他狗和未明确主体的称重内容不能自动归入本分类。
- 一条微博同时命中“偷吃”时，不因偷吃后的节食或补偿自动新增“胖瘦二象性”。
- 语义文档解释观众如何理解和编排内容，不会自动改变分类规则或关键词。
